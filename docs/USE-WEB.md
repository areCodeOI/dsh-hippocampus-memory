# Web 管理台使用教程

> 已装好插件后，在浏览器里管理记忆。手机/电脑都可以，不需要懂前端。
> 只想知道手机 App 怎么用，看 [USE-DSH-GO.md](USE-DSH-GO.md)。

## 1. 打开管理台

在浏览器地址栏输入：

```text
http://127.0.0.1:7337/
```

- 如果浏览器和 DSH 在同一台设备上，通常直接就能打开。
- 如果提示要 token：说明设置了 `HIPOCAMPUS_TOKEN` 或 `HIPOCAMPUS_AUTH=required`，
  把 token 填进去即可（找部署的人要，不要发到群里）。
- 打不开：先在 App「引擎」页重启引擎；或确认 7337 没被别的程序占用。

左侧是 7 个页面：**总览、记忆库、记忆星图、记忆树、异步任务、审计日志、设置与权限**。

## 2. 总览：先看健康状态

打开后先看四块：

- **记忆总量 / 待处理冲突**：冲突不是 0 就先处理冲突（见第 6 节）。
- **数据库大小**：太大说明记忆多或审计多，可以备份后清理。
- **分层分布**：人格/语义/情景/缓冲各多少。
- **最近记忆 / 审计尾迹**：确认写入是否正常。

这里只是看，不用改任何东西。

## 3. 记忆库：搜索、写入、编辑

### 搜索

1. 点左侧「记忆库」。
2. 顶部搜索框输入关键词，例如 `花生`、`PostgreSQL`。
3. 可以按「层」和「状态」过滤。
4. 点任意一行，右侧弹出详情。

### 写入一条

1. 「记忆库」页点「新增」。
2. 填内容（**一句话一件事**），选层（不确定就选 `episodic`）。
3. 重要性 0.1–10：9–10 是身体/账号/永久偏好；5–8 是习惯；2–4 是普通事件。
4. 点保存。重复内容会自动合并/强化，不会越写越多。

### 编辑 / 归档 / 删除

- 点行 → 详情 → 编辑：改内容、层、标签、重要性。
- 归档：以后默认搜不到，但可恢复；适合过时项目。
- 删除：默认进 7 天冷静期；期间再访问会自动恢复。永久删除需要管理员权限。

## 4. 记忆星图：看记忆之间的关系

- 节点 = 一条记忆；颜色 = 层；大小 = 重要性。
- 边：青色=巩固链、红色=冲突、灰色=共享标签、紫色=内容相似。
- 鼠标/手指：拖节点、拖空白平移、滚轮/双指缩放、点节点看详情。
- 右上角可切换节点上限（100/300/500）。节点太多时只显示最重要的一部分，这是正常的。

星图是用来“看结构”的，不用于精确搜索；搜具体内容用「记忆库」。

## 5. 记忆树：按空间和层浏览

- 按 `namespace → 层 → 记忆` 展开。
- 顶部输入框可过滤内容/标签。
- 点叶子同样打开详情。

适合多项目（不同 namespace）的人快速定位。

## 6. 冲突：最重要的一节

出现冲突说明：新写入的信息和旧记忆矛盾（例如旧的是“花生过敏”，新的是“不过敏”）。

处理步骤：

1. 打开「总览」或「记忆库」的「待确认」过滤。
2. 点开冲突，比较两条内容。
3. 判断哪条对：
   - **新的对**：编辑新条目，勾选确认，并把旧条目标记为被取代（详情里有“取代”选项）。
   - **旧的对**：把新条目归档或删除。
4. 保存后，总览里的冲突数会减少。

> 不确定时不要乱点；把两条内容复制给 AI，让它解释差异，再决定。

## 7. 异步任务：回放、备份、维护

点「异步任务」：

- **运行回放**：整理/衰减/合并记忆，建议每周一次。
- **创建备份**：后台复制一份数据库（结果里有文件路径）。
- **维护**：清理过期审计/任务并回放（默认每天自动跑一次）。
- **嵌入回填**：只有配置了嵌入 provider 才需要。

任务列表每 3 秒刷新；可看进度、结果、错误；管理员可取消。

## 8. 备份与恢复（强烈建议）

### 导出（最通用）

1. 点「设置与权限」→ 数据卡 →「导出」。
2. 浏览器会下载一个 JSON 文件。
3. 把它存到网盘/电脑；换设备时用「导入」恢复。

### 直接复制数据库

1. 找到数据库文件：默认是 `<项目目录>/.data/hippocampus/memory.db`。
2. 最好先停止服务/引擎，再复制 `memory.db`（以及同目录的 `-wal`、`-shm`）。
3. 恢复时放回同一路径，再启动。

### 注意

- 导入会做幂等处理（已存在的跳过），不会重复写入。
- 数据库**没有加密**；备份文件要自己保管好。

## 9. 设置与权限

- **服务信息**：版本、数据库路径、存储驱动、监听地址。
- **API key**：给别的程序用；角色分 reader / writer / admin；能限制 namespace。
  完整 key 只显示一次，丢了只能重新建。
- **导入 / 导出 / 备份**：见上一节。
- **嵌入 provider**：不配置也能用（本地词法检索）；配置后召回更“语义化”。

## 10. 审计日志

记录谁在什么时候对哪条记忆做了什么（增删改、冲突处理、key 操作）。

- 排查“谁改了记忆”时用。
- 支持按 action/actor 过滤。
- 审计有保留期，自动维护会清理。

## 11. 常见问题

**Q：页面空白/样式错乱？**
A：强制刷新；仍不行看浏览器控制台是否 CSP 报错，或重启引擎。

**Q：打不开 7337？**
A：引擎没起或端口被占；重启引擎，或换端口启动独立服务。

**Q：导入后没变化？**
A：导入是幂等的；看结果里的 `imported`/`skipped` 数字。

**Q：星图节点很少？**
A：只显示当前 namespace 和上限内最重要的节点；调大上限或检查 namespace。

更细的页面/字段说明见 [UI.md](UI.md)。
